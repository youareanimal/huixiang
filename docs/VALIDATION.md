# 回响验收记录

日期：2026-10-29（北京时间）。本轮构建版本：回响 0.4.3-preview。

## 待发布：好友文字聊天

- “好友 → 好友卡片 → 发消息”会按需连接官方云聊天，优先复用两人会话；没有会话时使用私密房间及明确好友邀请创建聊天，不上传本地备注。已有邀请须明确接受或打开对应好友私聊后加入，更新官方 `m.direct` 会话映射时保留其他条目。
- 普通文字支持发送后立即回显、前台三秒轮询、分页历史及最多 500 条的进程内记录。发送失败保留草稿，相同房间/内容在当前连接中重试复用事务编号；已确认发送后的同步失败单独提示，不误报发送失败。其他房间或不同内容的发送结果不能清空当前草稿。
- 接受邀请、发送、历史和回执均走同一账号操作队列。仅前台且最新消息可见的未加密会话发送已读回执，同一事件重复可见时不重复请求；查看历史或应用退到后台时不提前标记最新消息已读。
- 发送前重新读取完整成员及加密状态；两人私聊新增第三人或启用加密后阻止发送。复用已加密会话时保留只读状态，不新建未加密替代房间。创建返回成功后即使后续映射写入失败，重试仍复用已确认的房间；创建结果未知时不盲目重复创建。
- 本轮使用合成账号、传输与 UI 数据验证，没有给真实好友发送消息、建立会话或接受真实邀请。官方服务器上的端到端收发、手机后台和真实网络行为仍待真机验收；不支持 E2EE 解密、图片附件或后台消息推送。协议依据：[Matrix Client-Server API](https://spec.matrix.org/v1.11/client-server-api/)。
- 最终源码与测试编译成功，48 项专项与回归测试通过（协议 22、Android 26；0 失败、0 跳过）。覆盖好友入口、会话创建/恢复、邀请、失败重试、发送后同步失败、草稿隔离、加密/成员变化、历史耗尽、前台可见性与回执去重，以及账号和导航回归。首次界面测试对禁用输入框、占位文本和 Robolectric 重绘的等待已修正并复验；证据与最终源码指纹位于 `dist/verification/friend-chat/summary.json` 和 `final/`。
- 此功能尚未生成或发布新版 APK，现有 0.4.3 更新测试包不包含这些变化。下次发行按既定要求使用 GitHub Actions 构建与 GitHub Releases 发布。

## 0.4.1 邮箱、头像与密码显隐

- 全部成功后才原子替换 Android Keystore 加密存储。任一步失败会保留旧账号，并尝试撤销本次新建的 myTeamSpeak 会话。
