# 聊天连接与发送修正

本次针对“点击好友聊天报 503”以及服务器频道／私聊的发送行为。503 的在线根因仍需联网确认；以下改动不代表官方聊天服务已恢复。

- 好友聊天先读取账号域的公开 Matrix 客户端服务发现配置。只有该域明确委派的官方 HTTPS 根地址可接收后续请求；不枚举分片、不改变账号 Matrix ID、不跟随重定向。
- 缓存的连接在登录或首次同步时返回网关／网络错误，才向账号服务重新获取聊天配置。只有官方返回的域、用户或密码发生变化才重试，避免重复请求同一失效配置。正常缓存会话仍可直接使用，不依赖导入的 myTeamSpeak 会话一直有效。
- 错误代码区分 `CHAT_CREDENTIALS_HTTP_503`、`CHAT_LOGIN_HTTP_503` 和 `CHAT_SYNC_HTTP_503`，分别表示获取聊天凭据、登录和首次同步失败。不记录密码、令牌、响应正文或聊天内容。
- 服务器文字消息按 `return_code` 关联发送回执。成功回执只清除对应会话且内容未变化的草稿；权限拒绝、接收人离开或断线时保留草稿。断线后不自动重发送达状态未知的消息。
- 频道与私聊草稿分别保存；过长文字按 UTF-8 大小拒绝并提示，不再静默截断。失败的私聊发送从回显接收人队列移除，避免下一条消息进入错误会话。
